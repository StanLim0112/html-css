# Portfolio visual hierarchy: my answers

## 1. Which CSS rule makes the strongest text on your page?
The (Line 45-49 of style.css) It has the font-size of 3rem which makes the h1 element the largest font size of the page itself.

## 2. Which CSS rule makes the paragraph text easier to read?
The line-height property that is found throughout the style.css makes the paragraph text easier to read since it is able to create space between the lines to not make it look so cluttered and allows the user to read more easily.

## 3. Which color did you use for actions or emphasis?
I used the color #453bf1, which is a darker blue on a very light teal/blue color background so that it is accented and give it more contrast to let the users know where/what to navigate or what to briefly know

## 4. Which spacing choice separates one content group from another?
(line 126-130 of style.css) I had the gap property in the .work-list selector to create a uniform spacing for the .work-list children to have an equal spacing across the boxes/content

## 5. What becomes more difficult to read quickly if each text element has the same size and color?
The main purpose or summary of the content itself becomes more difficult. For example, if the title and summary/details of the page is all the same color and sizing, the user will be confused on what to find for or focus on. Essentially, if all the text element has the same size and color, the reader must go through meticulously to find what is the important info
