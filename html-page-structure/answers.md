# HTML page structure: my answers

## 1. What is the job of the `head`?
The head basically holds the information of the browser which includes the format as well as the title of the tab itself

## 2. What is the job of the `body`?
The body itself is for the entire content of the website as well as information of the website itself

## 3. Why does `<title>` change the browser tab, and not the visible page?
Because the <title> itself is in the head tag and the head tag is basically an invisible rule created to format the tab header as well the the format and rule of the web page itself

## 4. When must you use `<ol>`, and not `<ul>`?
You use <ol> whenever you want to have steps or rankings of a group of data to show them in a neat and ordered listing, whereas <ul> is used to show a general group of data that does not need steps or ranking.

## 5. Why must an image have useful alt text?
It is to show the description or info in case the user is not able to tell what the picture is.

## 6. What connects a `<label>` to an `<input>`?
the for="email" and the id="email" which uses the same data value which connects both the label and the input
