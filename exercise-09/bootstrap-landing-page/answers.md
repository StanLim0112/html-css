# Bootstrap landing page: my answers

## 1. Which Bootstrap classes did you use for the navbar?
There are multiple bootstrap classes that is used for the navbar.
A few of them being "navbar, bg-white, border-bottom" that is used for the positioning itself. There is also "container, navbar-brand, fw-bold" that is used for the layout of the navbar itself. The main hamburger shaped button comes from the classes "navbar-toggler, navbar-toggler-icon". Lastly, for the collapsing part "collapse, navbar-collapse, navbar-nav" is used and the links is "nav-item, "nav-link"

## 2. Which value on the navbar button points to the menu?
The #mainMenu from data-bs-target as well as the mainMenu from id which is located at (Line 19 and 23 of index.html respectively)

## 3. Which grid classes changed the layout of the hero section?
The "container" is the one that makes it responsive, while the "row, align-items-center" is the one that makes it centered vertically and creates a horizontal flex row.

## 4. Which card classes did you use?
For the service's cards section I used a more simple approach of classes which is (card, h-100 and card-body). As for the contact form section, I used (card, border-0, shadow-sm, card-body and a few utilities)

## 5. Which styles did you put in `custom.css`, and not as Bootstrap utility classes in the HTML?
I only change simple custom stuff like colors. For example, I changed the background tints and text colors in body, .hero-section, .services-section, and .contact-section. Apart from that, I also edited the border color and larger rounded corners on .info-panel and .service-card which uses "border-radius and border"
