# Typography: my answers

## 1. Which text must the reader see first?
The main heading or overall goal/title of your website which is the "Build your first CSS habit."

## 2. Which CSS choice makes that text the strongest?
Referring to question 1, the text is the strongest because it has the CSS property of "font-size: 3rem;" which makes it the largest font size in the entire page. Apart from that it also has a small line height for a heading.

## 3. Which text is supporting information?
(Line 12 of index.html) Community Workshop since it is bold and orange and serves as the heading supporter as an information

## 4. Which color is used for an action or for emphasis?
An accent color is used whenever an action or emphasis requires bold highlighting (popping colors) that easily shows or attracts a user's attention. For example the kicker and action button uses the color #c2410c to make it pop out.

## 5. Which spacing choice separates one content group from another?
A more preferred spacing choice is the property "gap". An example would be from (line 126 of style.css). It creates an uniform space gap between the content (flex items), so that users can read through the information quickly without being cluttered.
