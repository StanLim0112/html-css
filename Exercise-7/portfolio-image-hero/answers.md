# Portfolio image hero: my answers

## 1. Which image goes in the HTML, and why?
The images/portfolio-desk goes in the HTML since it is a featured image to show the user about the page or to extract information from it

## 2. Which image goes in the CSS, and why?
The images/portfolio-background goes in the CSS since it is a decorative image that is only used to enhance the asthetic of the website itself and does not play an important feature that the user needs to know

## 3. Which CSS property stops the content image from stretching?
3 parts play in this role actually, at (Line 127 of style.css at selector .feature-photo) The width, height and object-fit is the one that is stopping the content image from stretching. But the important one is the object-fit property, the width and height is there to limit the image according to the rule that is set by object-fit

## 4. Which element makes the boundary for the positioned label?
(Line 121 of style.css) The ".image-panel" element is the one that sets the boundary for the positioned label with the "position:relative" property and value.

## 5. What did you do to keep the text easy to read?
For example for the content of the page which is in the class "hero-content" I created the CSS rule to make a panel with an almost solid background of white to make the text easy to read so that the text itself won't blend into the background image
